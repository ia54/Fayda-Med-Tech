Existing targets are refused; only a database successfully created by this helper can be dropped. Original SQLite fixtures and operational servers/data/keys are untouched.

Each existing CI matrix engine (MySQL 8 and MariaDB 10.11) uses its native dump and client. With synthetic fixture writes quiesced, the test dumps all tables and captures the uploaded prescription's private original file. It retains an independent manifest digest and binds file inventory/path/size/hash to actual database rows, then validates again after import. Bounds: 16 files, 1 MiB per file, 8 MiB total, 32 MiB SQL dump. Paths/traversal/links are refused. This is a bounded CI fixture helper, not a streaming general-purpose production backup tool.

Checks: every table's row hashes and schema definition survive; original source bytes and SHA-256 are retrievable through application routes for assigned pharmacist and technician; biller/attorney/firm/provider deny 403; foreign tenant/unassigned site deny 404; anonymous denies 401. Missing/tampered/linked backup files, changed manifests, altered dump digest and a deliberately invalid SQL import fail; no partial target remains and original source rows/files remain unchanged. Existing-target refusal preserves the successful restore. Explicit rollback drops only the owned restore database, removes its private target, and the original API fixture remains usable. Final cleanup removes the temporary tree. Laravel HTTP facade forbids provider requests.

Authentication scope: the existing PharmacyWorkflowTest supplies synthetic authenticated users/access-token objects and disables its two-factor middleware. This proves application route/role/tenant/site boundaries after restore; it does not prove bearer-token signature verification, login, MFA enrollment, browser sessions or hosted TLS/gateway behavior. No hosted accounts are created.

## Actual source storage and encryption requirements

`api/config/filesystems.php` defines the local private documents disk at `storage/app/private/documents`; it is not the public disk and must never be web-served or linked by storage:link. PharmacyController source upload stores original bytes and database path/hash/size metadata; sourceFile checks existence and SHA-256 before a private/no-store attachment response. It does not transparently encrypt/decrypt document bytes. The helper additionally checks database byte counts; do not confuse that with a sourceFile runtime size check. Host/backup encryption at rest and access controls remain operational requirements.

`User::$casts['ssn']` and `ApiCredential` key/value casts use Laravel encryption: matching APP_KEY is required. The rehearsal saves a clearly non-real encrypted marker through the User cast, verifies SQL does not contain the marker in plaintext and verifies decryption after restore with the same disposable test key. It does not recover a real key or credential. Passport public/private keys, OAuth clients/tokens, MFA secrets/session/configuration and gateway settings must be retained through a protected operational backup procedure; the test public-key fixture cannot mint tokens, so this test makes no signing-key recovery claim.
