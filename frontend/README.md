# ⚛️ FAYDA-MEDTECH

A modern starter template for building scalable React applications with:

- 🌀 **React**
- 🧠 **Redux Toolkit** for state management
- 🎨 **Tailwind CSS** for styling
- 🌐 **React Router DOM** for client-side routing
- ⚙️ **Vite** (or CRA – update accordingly)

---

## ✨ Features

- Modular folder structure
- Global state management with Redux Toolkit
- Utility-first CSS using Tailwind
- Routing with React Router
- Fast development with Vite (or CRA)
- Minimal and clean setup

---

## 📦 Installation

### 1. Clone the repository

```bash
git https://github.com/dotprogrammers/fayda_med_landing.git
cd fayda_med_landing
```

### 2. Install dependencies 2

```bash
npm install
# or
yarn install
```

### 3. Start the development server

```bash
npm run dev
# or
yarn dev
```
